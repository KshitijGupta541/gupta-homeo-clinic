# 🏥 Gupta Homeo Clinic

A modern full-stack Clinic Management & Appointment Booking System built for a real homeopathy clinic.

## 🌐 Live Demo

(https://guptahomeoclinic.online/)

## 🚀 Features

- Online Appointment Booking
- Patient Management
- Admin Dashboard
- JWT Authentication
- Responsive Design
- Contact & WhatsApp Integration
- Treatment Information
- Secure Backend API

## 🛠️ Tech Stack

### Frontend
- React
- Vite
- Tailwind CSS
- React Router
- Axios

### Backend
- Node.js
- Express.js
- MongoDB Atlas
- Mongoose
- JWT Authentication

### Deployment
- Netlify
- Render
